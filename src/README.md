# src

Source code. This project has one application, so this folder has one thing in it.

| Folder | What it is |
|---|---|
| [UserManagementAPI/](UserManagementAPI/) | The ASP.NET Core Web API — the whole application. |

Keeping the code under `src/` rather than at the repository root separates it from the
documentation, the build plan, and the repository's own files, so the top level of the repository
stays readable.
